# Paper variants

- `main/UrbanEV_Evidence_Audit_Main.pdf`: compact submission main text.
- `supplement/UrbanEV_Evidence_Audit_Supplement.pdf`: detailed locks, run lineage, batch latency, and checklists.
- `archive/UrbanEV_Evidence_Audit_Archive.pdf`: immutable 42-page archive copy from the completed internal audit paper.

The three variants share section, table, figure, result, and bibliography sources where applicable. `archive/main_archive_original.tex` preserves the original archive entrypoint; `archive/main_archive.tex` is the rebuildable public entrypoint.
