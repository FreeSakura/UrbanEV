# Paper variants

- `main/UrbanEV_Evidence_Audit_Main.pdf`: compact submission main text.
- `supplement/UrbanEV_Evidence_Audit_Supplement.pdf`: detailed locks, run lineage, batch latency, and checklists.
- `archive/UrbanEV_Evidence_Audit_Historical_Archive_v0.9.0.pdf`: historical wrapper with an explicit non-normative cover followed by the immutable 42-page archive.
- `archive/UrbanEV_Evidence_Audit_Archive.pdf`: preserved original 42-page archive bytes; not the current submission version.

Main v0.9.1 and Supplement v0.9.1 remain the released preprint pair. Working-branch PDFs are labeled as drafts after v0.9.1. The variants share section, table, figure, result, and bibliography sources where applicable. `archive/main_archive_original.tex` preserves the original archive entrypoint; `archive/main_archive.tex` is a visibly labeled historical-layout rebuild from the current working text.
