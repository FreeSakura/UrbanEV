## 目前可支持的判断

当前数据支持部分长历史和普通线性预测收益；尚未建立专用动态结构稳定优于同信息强参考的证据。完整六折公开成绩和近期方法的同任务比较仍不齐全，因此不能给出全球 SOTA 排名或单一差距百分比。

分位适配、双风险、长历史、交互等实验使用不同的窗口和选择规则。它们在[综合报告](reports/PROJECT_REPORT.md)中按研究问题解释，不能把每行改善百分比合成一张排行榜。
