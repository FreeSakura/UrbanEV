# 残差信息实验：先发现可外推信号，再打开验证段

> 阶段记录：下文保留原研究时点的结论和执行范围；当前公开状态见[项目状态](../PROJECT_STATUS.md)。目录迁移不改变原结果。

依据[推导包](../theory/RESIDUAL_DERIVATION_PACKAGE.md)，本轮检验的主张是：从占用特征线性空间中剔除可预测部分后的滞后时长，能否改善冻结全区域Chronos的误差，并保持MAE。独立的结构主张是：残差化是否比普通时长拼接修正更好。两个门分别报告，不互相代替。

协议为[RESIDUAL_INFORMATION_V1](../../configs/research/RESIDUAL_INFORMATION_V1.json)，先提交实现再读取新数据。第三折训练边界1747，验证边界1966，测试边界2184；此前折末段进入扩展训练，会明确披露。既往项目接触过更广数据集，不称全局盲测。

阶段一仅准备1747行。基础预测为冻结Chronos-2 full275、历史168、H3/H12，不重新训练权重。训练原点从192开始，间隔12小时，目标全部落入相应较早训练段。三个时间截点720、1056、1392，各留出后续168小时评价，所有投影、标准化及修正头都只用截点前数据。

系统包括原生预测、均值偏差修正、占用残差ridge、重复特征ridge、原始时长拼接ridge、正交时长修正及错配时长修正。所有有监督头采用lambda0.01，所有系统允许相同α集合{0,0.25,0.5,1}；选择只发生在训练内部。正交方法多估计一个D对X的OLS投影，因此不能称总拟合参数与原始拼接完全一致，报告额外投影系数数量。

信息门：正交时长相对最佳非时长控制宏RMSE至少改善1%，MAE不恶化，任一窗口/H的RMSE恶化不超过1%，至少两个滚动窗口平均RMSE改善，并胜过错配时长且MAE不恶化。结构门另要求比原始时长拼接提升至少1%且MAE不恶化。α=0是回退失败，不能计为通过。

只有信息门通过，才准备1966行前缀、固定每个系统的α并用1747行以内数据重拟合，在第三折全部验证原点评价。验证段不再选择步长或正则。若信息门失败，脚本保留缓存和结果，第三折验证不打开，也不调整门槛再跑。

预计阶段一约260次GPU预测及轻量CPU线性拟合，约3–6分钟；通过后阶段二增加约430次预测。输入、预测、投影结构和模型权重保存在本地，GitHub只发布汇总、推导、协议及可复核哈希。时间采样间隔12小时与正式逐小时评价不同，训练内部成绩不得写成标准验证成绩。

启动方式：

```bash
python scripts/research/residual_information.py --stage screen --csv local-data/train-f3.csv --duration local-data/UrbanEV/duration.csv --info local-data/UrbanEV/inf.csv --model-dir local-data/chronos2 --output local-data/residual-screen
```

使用此前验证的Chronos专用环境；阶段二命令添加`--stage confirm --screen local-data/residual-screen`，输出新目录。程序验证阶段一信息门、输入前缀、缓存及模型身份后才执行。该第二阶段是下一开发验证，不是最终测试或独立确认。
