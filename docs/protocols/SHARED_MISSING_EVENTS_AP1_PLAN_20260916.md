## 2. 对首轮数学的独立判断

### 2.1 主体推导成立的理由

令 M=K-L+1。旧 r 截断在 L-1，仍能判断新输入 1 是否完成一个 L 游程；d=0 时最近游程刚完成，d=M 时所有历史游程均已过期。时刻 t 的最后 K 个值中含完整游程，当且仅当最近结束位置 q 满足 q>=t-K+L，等价于 d<=M-1。因此在同一处理时刻，相同 (r,d) 的前缀拥有相同的后续可行转移及输出。

在逐位置可行集合、预测固定、损失可加的设定下，最短/最长路径递推得到精确可达端点。L=1、L=K、K=1 均与该定义相容。不存在需要为持续 L 个高记录而把真实连续驻留时长偷换进来的理由。

分量同号判据和端点可达性充要条件也成立。保守多连边只会使同号判据少判出一些“无需优化”的情况，不会错误地宣布独立界精确。

### 2.2 必须保留的限制

- “精确”指已声明相容集合上的精确端点，不是总体置信区间，不证明下一周有效。
- 已知位被视为正确；仅缺测自由补全。未处理错误传感器读数、错位时间戳、未知时间格点。
- 二元有限损失的仿射分解适用于逐样本可加损失；不能直接推广到 AUC、F1 等非逐样本可加指标。
- 人工补全评价标签时预测必须保持不变。重新补全输入并重新预测，比较的是另一个对象。
- 任意局部面板要按预测原点定义。若一块含 P 个原点，标签支持集通常含 P+K-1 个底层时刻。不能把底层序列裁成 P 点后悄悄少算 K-1 个标签。
- 相邻原点块可能共享标签支持中的缺失位；全期精确界须全期求解，不能把各块端点直接相加。独立站点可加的前提是没有额外跨站补全约束。
- 一个达到端点的补全见证证明端点可达，不单独证明最优性。正式“证书”可附 Bellman 势函数不等式及端点路径；接近零的判定需用外向舍入或精确算术复核。无需把所有求解都升级为形式化验证。

### 2.3 可以直接补入理论稿的状态计数

这不是新的性能实验，而是对给定转移系统的独立推导。

全字母表可达状态的精确数量为：

    S(K,L) = 1 + L + sum_{d=1}^{K-L} min(L,d).

证明：d=0 时只能有 r=L-1。1<=d<M 时，最近游程之后第一位必须为 0，否则最近游程会刷新；故 0<=r<=min(L-1,d-1)，有 min(L,d) 种，均可由 1^L 0^(d-r) 1^r 实现。d=M 时 r=0,...,L-1 均可实现。三类相加即得。

例如 K=24,L=3，实际可达状态为64，而69是笛卡尔积槽上界。

对识别语言 R={0,1}* 1^L {0,1}^{0,...,K-L} 的确定性输出自动机，上述可达状态还可证明两两可区分：

- r_h>r_l 时，后缀 1^(L-r_h) 0^(M-1) 使前者最终事件为真、后者为假；
- r 相同、d_1<d_2 时，后缀 0^(M-1-d_1) 区分二者。

所有状态均可在足够长且等长的前缀上到达，因此外部的 K-1 步预热计分规则不破坏这一区分论证。可据 Myhill–Nerode 的标准论证给出该语言的最小 DFA 状态数；这不是所有最优化算法的时间或空间下界，也未证明此计数在文献中首次出现。它应作为精确定位结果，而非新的“全球首创”宣传。

## 4. 最重要的近邻与算法对照

### 4.1 更强的已有方法反驳

Demassey、Pesant、Rousseau（2006），Constraints，第3节已经将序列变量约束展开为分层有向图，用最短/最长路径处理代价；脚注1明确可把代价细化为变量位置、取值和自动机状态的组合。当前 w_t(q,x)=c_t×event(delta(q,x)) 正是这种状态/时间相关弧代价。因此“系数随时间变化”“累加多个事件”“前后向求界”本身不是超出该框架的理由。

Mohri（2002）的半环最短距离框架，Waga（2019）的定量模式监控，以及 Ganardi 等（2018）的滑窗自动机研究，同样是算法定位需要正面对照的原始工作。

持续事件在流前缀上可写为正则语言：

    R = {0,1}* 1^L {0,1}^{0,...,K-L}.

通用正则编译→确定化/最小化→按时间展开→限制缺测输入→累加接受状态代价，构成直接的通用精确基线。所有终态均允许终止，接受标志只用于每步计分；不能误把它设置成“只允许最后一个窗口为正”。

### 4.2 必做对照

| 对照 | 作用 | 公平性要求 |
|---|---|---|
| 逐窗独立界 | 弱标签一致性基线 | 同模型、同目标、同N |
| 两两标签蕴含/等价约束的LP界 | 检查六例是否仅是低阶逻辑约束的收益 | 构图不能只选六个正例；计入前处理成本 |
| 通用正则编译+最小DFA+加权路径 | 最近邻主算法基线 | 独立生成自动机，不手工注入(r,d)；同浮点/编译条件 |
| 同一(r,d)图上的通用路径实现 | 分离状态构造与底层实现优化 | 不用纯Python对Numba制造“算法优势” |
| 用户已有MILP的完整分层样本 | 独立目标编码及通用求解成本 | 覆盖缩窄/不缩窄、可判/不可判、不同缺测形态，不只赢家 |
| 旧V3后缀DP | 仓库回归及历史改进 | 不能继续作为唯一主基线 |

Dervovic、Cashmore（2025）是评价问题近邻；其第3节已讨论乐观/悲观界，第4节是多重插补。本文的独立Brier界是对相同思想在当前配对可加目标上的实现，不冒称作者论文的原生Brier算法；PEMI的概率分布也不应被当成同一相容集上的确定性区间。

## 5. 下一轮最高优先级理论问题：不一致性究竟付出多少代价？

只取模糊标签且c_s≠0的窗口集合A。令 y_s^- 是独立下界偏好的标签：c_s>0时为0，c_s<0时为1。定义：

    Gamma^- = min_{z∈Z} sum_{s∈A} |c_s| 1{E_s(z) != y_s^-}.

则：

    lower_joint = lower_ind + Gamma^-/N.

上界有对应 Gamma^+：

    upper_joint = upper_ind - Gamma^+/N.

证明仅需逐项减去其独立最小值/最大值；每个违反偏好标签的代价恰为|c_s|，相加并优化。无额外统计假设。

这把“端点不可达”量化为必须牺牲多少独立逐窗收益。B能在原不确定区间上获胜，当且仅当：

    lower_ind <= 0, upper_ind >= 0, Gamma^-/N > -lower_ind.

A获胜则检查 Gamma^+/N > upper_ind。边界等于零只给非严格比较。

独立区间宽度还满足：

    W_ind = (1/N) sum_{s∈A} |c_s|.

因此原始缺失率不是充分解释变量；需要依次考察模糊标签数量、系数权重、分量符号混合、逻辑冲突代价，以及它是否超过距零的余量。

### 5.1 二元冲突为什么可能是强反驳

用户报告六例都能找到两个窗口的不相容要求。若仅为 E_i=1,E_j=0 不可同时实现，则有有效约束 e_i<=e_j；双向蕴含给等价。加入这些约束和0<=e_s<=1，线性目标求得有效的外界。它可能在没有全轨迹DP时就给出全部六个判断，必须实测，不能事先认定不会。

单个冲突核U至少贡献 min_{s∈U}|c_s| 的违反代价下界。但多个核可能共享同一个被牺牲标签，不能简单将该下界相加。需要不重叠核、容量约束的冲突打包，或直接求加权满足问题。

### 5.2 高阶效应确实可能存在的解析反例

四个底层位全未知，K=2,L=1：

    E0=z0 OR z1; E1=z1 OR z2; E2=z2 OR z3.

要求 E0=0,E1=1,E2=0 两两都可满足，但三者不能同时满足。因此全体两两标签关系不能恢复完整可行标签集合。

取 a=(0,1,0)，b=(0.5,0.5,0.5)，则配对总常数为0.25，c=(1,-1,1)。独立界和所有两两关系的LP界均为[-0.25,0.75]；真实标签恒满足 E1<=E0+E2，联合界为[1/12,0.75]，从而B严格更好。

这是本次分析中的解析构造，用来证明不同对照层级确有区别，不是新增自然实验，也不能反过来定制真实预测器制造正例。

为验证应用价值，同时统计“可确认的最佳模型/未被确定支配的候选集合”是否改变，而不只统计任意配对多了一个排序。在所有补全下Brier更好，不等于报警费用更低；不在本轮宣称部署、维护成本或风险损失改善。

## 8. 自然缺失与人工遮蔽

自然缺失是主要外部实证，功率180天只算探索性补充。后续功率新范围即使仍零新增判断也必须完整保留，不再滚动扩大前缀直到出现正例。

人工遮蔽只在预先按完整性选定、具备完整标签真值的时段上做，不能按结果挑场景；完整性选择本身的样本偏差需声明。固定既有IID10%、IID30%、10%成块三机制，在同一完整时段和同一模型配置上配对。先遮蔽评价期底层数据再按预测时刻重建因果输入；固定训练前缀与模型权重，隐藏真值只用于事后检验。

报告插补/仅完整标签比较的错误定向、确定性界的拒绝定向、余量和宽度。零违反主要验证实现与定义一致，不是估计95%置信覆盖率。可用不同遮蔽布局诊断结构机制，但不能把人工收益换算成自然故障场景收益。
