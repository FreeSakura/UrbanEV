# UrbanEV 项目综合报告

整理日期：2026-09-15。该报告整合公开仓库的代码、理论、实验与论文；精确结果由[结果总览](../../results/README.md)连接到原始公开汇总。日期实验记录保留其原结论。

## 研究对象与演进

项目研究城市公共充电设施的占用预测，主要目标是 275 个区域的小时占用率。早期工作审计配置、运行、预测和主张之间的证据链；后续工作转向观测信息、长历史、动态结构以及同协议强基线比较。历史论文反映审计阶段，不应作为当前预测方法已获全面验证的依据。

## 已有结果意味着什么

**普通参考必须足够强。** 已完成的统一开发比较使用两种 ridge 和五种神经配置；RIDGE_OD 在该核心表中的四 H 平均 RMSE 与 MAE 最低。这个结果来自一个已曝光的开发窗口，训练预算、输入轨道和初始化范围都有限；不能推广为“线性模型普遍优于 TimeXer”或全球排名。精确数值、实例数和完整支持检查见[开发核心表](../../results/README.md#开发集核心比较)。

**历史信息有价值，具体结构仍需证明。** 长历史来源消融在两个开发窗口发现，给定长 O 与单个 D 后，更早的 D 仍有收益；重复 O 控制未解释掉该轮增量。另一方面，短摘要弛豫及按真实时间顺序平滑 D 系数未形成所期待的特定优势。这支持继续研究历史表示，不支持把某一种先验直接当作有效机制。[长历史报告](forecasting/LONG_HISTORY_SOURCE_REPORT_20260913.md) · [正则化报告](forecasting/DURATION_LAG_REGULARIZATION_REPORT_20260913.md)

**交互与纠错证据有限。** 乘性交互有开发 RMSE 线索，但存在 MAE 代价和种子分化；后续稳定化未形成总体稳定优势。前向残差实验的九个前向实例都选择 epoch0，等于 ridge 底座；这不能当作非零纠错器迁移成功。固定旧底座下的普通线性纠错有两窗口收益，但未超过完整 ridge。[交互](forecasting/CONDITIONAL_OD_INTERACTION_REPORT_20260913.md) · [前向迁移](forecasting/FORWARD_RESIDUAL_TRANSFER_REPORT_20260913.md) · [固定底座](forecasting/FIXED_REFERENCE_CORRECTION_REPORT_20260913.md)

**适配收益与变量无效不是同一结论。** 分位输出适配、连续步长、双风险与电量实验保留局部收益、风险权衡和原协议负结果。同信息 ridge、硬门或普通校准控制限制了专用结构主张；某轮 NO_GO 不证明空间、时长或电量信息普遍无用。[研究地图](../research/README.md)

**理论与合成结果提供边界。** 粗粒化记忆和观测可识别性研究帮助明确“哪些观测足以预测”的问题；固定人工系统中与已知参数 HMM 一致的结果是机制检查，不是 UrbanEV 真实模型优势。历史 V3 配对审计研究则讨论缺失观测下的事件界，不能与占用率 RMSE 混排。[理论目录](../theory/README.md) · [V3 记录](audit/PAIRED_AUDIT_V3_REPORT.md)

## 完整比较还缺什么

正式六折合同已经固定数据版本、24 个折×H 单元、训练与选择规则、作者核心及基础模型清单。主分支目前保留注册材料，尚没有全量完成和评分回执。72 次 ridge、432 次神经训练等都是登记预算，不能提前写成实际成果。后续应核对任务、预测和分数覆盖，分别报告原生输出、信息轨道、别名及成本。[状态与依据](../PROJECT_STATUS.md)

此外，近期专用方法仍有数据版本、目标、归一化及分割差异待核查。因此现阶段可以报告开发证据和方法限制，尚不能声称已建立 SOTA。历史测试已经曝光，重新冻结协议也不能抹去这种曝光。
