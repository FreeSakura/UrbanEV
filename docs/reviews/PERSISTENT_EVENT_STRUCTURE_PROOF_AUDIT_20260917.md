## 重点修正

- 原本未限定参数的“覆盖即可完整描述”被缩小到 K≥2L−1；短窗口保留桥接反例。
- 私人见证充要条件只在上述范围作为双向判据；范围外若找到有效二元非一元覆盖仍可证明不完整，全部通过则不据此宣布精确。
- OR封闭是可行标签集合的性质，未声称对原始轨迹直接OR后标签逐位分配律成立。
- 已区分二元约束、连续凸包、当前权重目标及严格判向四个问题。
- 已确定标签全部固定；影响区间描述只在剔除基准真标签后使用。
- 无模糊标签、单标签、N=2、L=1、K=L及序列两端均由定义或反例范围单独覆盖。
