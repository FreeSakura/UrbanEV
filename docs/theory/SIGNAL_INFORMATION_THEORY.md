# 从信息增量到可检验的预测贡献

此文说明[固定复核方案](../protocols/SIGNAL_REPLICATION_PLAN.md)所能支持的理论结论，不把统计恒等式当作具体模型优于SOTA的证明。令Y为未来某区域某步的占用率，X为可用占用历史，D为预测原点前已取得的滞后时长。变量有有限二阶矩。

## 1. 信息存在与模型学到信息是两件事

记F=σ(X)、G=σ(X,D)，则F⊆G。平方风险最优预测为mF=E[Y|F]与mG=E[Y|G]。展开平方并用E[Y−mG|G]=0以及塔式法则，有

$$R(m_F)-R(m_G)=\mathbb E[(m_G-m_F)^2]\geq0.$$

证明：Y−mF=(Y−mG)+(mG−mF)，交叉项条件于G后为零，取期望即得。对全部区域和H步的平均平方风险，同式逐坐标相加成立；宏RMSE是多个平方风险开根后再平均，不能直接当作上述风险差。

信息增量为零当且仅当两个条件均值几乎处处相同。这不要求Y与D条件独立；D仍可能提供方差或分位信息。反过来，某个有限模型加入D后变差，也不否定信息的存在。

对仅用独立训练集拟合后固定的fF、fG，有精确分解

$$R(f_F)-R(f_G)=\mathbb E[(m_G-m_F)^2]+\mathbb E[(f_F-m_F)^2]-\mathbb E[(f_G-m_G)^2].$$

故信息收益可以被估计误差、模型错设或优化误差抵消。这里的独立性要求是理论总体风险的条件；实际UrbanEV连续序列与已曝光开发集不满足简单IID实验条件，应通过时间划分和相关性保留的分析限制推断范围。

## 2. 为什么复制特征是必要控制

考虑已标准化设计X、平方损失ridge：minβ ||y−Xβ||²/n+λ||β||²。若复制为[X,X]，预测依赖θ=β1+β2。对给定θ，最小惩罚在β1=β2=θ/2处取得，等于λ||θ||²/2。因此复制同一信息等价于原特征上的惩罚减半（不罚截距的约定保持）。

这说明“更多列之后变好”未必来自新信息。对照复制特征可以暴露这类效应；它不完全排除所有正则化或模型类差异。固定错配D保留部分时长分布，却改变区域对应关系；若错配同样有效，需要考虑全市共同因子。一次错配只是有限否定对照，不是条件随机化检验或因果识别。

## 3. 为什么区域相关性不能保证有效上下文

对冻结基础模型f与分区P，定义R(P)=E[||Y−fP(X)||²/(NH)]。相关系数刻画输入之间的线性共同变化，而分区风险还依赖目标、预测步长、模型内部注意力和训练分布。最大化组内相关性并不存在一般的R单调性保证。

即使Z与X高度相关，它也可能不改变E[Y|X]；即使额外上下文含预测信息，冻结f也可能不会利用它。因此当前相关分组的定位是可复现的简单预测策略。要成为方法贡献，需相对随机分组和全区域稳定获益，并解释何时失效，不能仅凭分组图像或训练相关性论证。

## 4. RMSE改善不能替代MAE与可用性检查

绝对损失的最优点是条件中位数；条件均值增量式不能推出任意模型的MAE同时改善。复核同时报告两种误差，MAE差值区间跨零时只能说点估计未恶化，不能说稳定非劣。

上述信息集合G只允许预测当时可取得的D。小时标签、数据发布延迟及预处理若不明确，离线D不能自动被视为线上可用信息。现有数据的时间区间累计小时单位已获文档支持，但精确端点和发布时间尚未确认，因而现阶段只作离线预测研究。

## 5. 对下一步实验的约束

先完成固定的跨窗口、跨骨干对照。若只有ridge有效，则研究重点转向基础模型如何保留增量信息，而不是把ridge收益宣称为通用增益。若只有部分H有效，则保留异质性，禁止事后只报有利H。若两个骨干均通过，仍需更多开发划分、明确数据版本及时间可用性，并与同任务强方法比较后才讨论SOTA。任何后续模型变更都应另立协议，不回写本轮推进门。

## 6. 可反哺下一实验的残差可预测性判据

先固定基础预测f0(X)，令e=Y−f0(X)，Z是仅从可用历史构造的时长特征。可以用训练期交叉拟合从D中去掉由X可预测的部分，但有限模型得到的残差不等于真正条件创新。对线性修正wᵀZ，记Σ=E[ZZᵀ]、c=E[Ze]，则平方风险的改善精确为

$$\Delta R(w)=2w^\top c-w^\top\Sigma w.$$

若λ>0且采用总体ridge解wλ=(Σ+λI)⁻¹c，代入可得

$$\Delta R(w_\lambda)=c^\top(\Sigma+\lambda I)^{-1}(\Sigma+2\lambda I)(\Sigma+\lambda I)^{-1}c\geq0.$$

推导只需展开(e−wᵀZ)²；非负性来自中间矩阵半正定。该式针对总体二阶矩与未裁剪平方风险，不是有限样本拟合、宏RMSE或MAE的收益保证。它提供的实验问题是：时长特征是否对基础模型尚未解释的误差有可外推的相关性c，而不是仅问D能否预测Y。

下一协议应先在训练内部的滚动留出中检验这个问题，并把仅占用历史修正、重复特征及错配时长修正作为等容量控制。如果训练外误差相关性也不能保持，停止扩大修正模型；若能够保持，才冻结低容量修正并评价新的开发窗口。本轮未运行这一新候选，不把它写成已有成果或重启旧单纯形头。
