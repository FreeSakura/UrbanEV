# AP1：可识别性层次、冲突代价与通用算法定位

本补充承接 [AP0 证明](SHARED_MISSING_EVENTS_COMPRESSION.md)，对象仍是固定概率预测、给定有限面板和逐位置自由补全的二元观测。结果不包含总体置信推断或真实物理轨迹恢复。

## 1. 状态精确数与最小 DFA

令 M=K−L+1。可达状态数为

$$S(K,L)=1+L+\sum_{d=1}^{K-L}\min(L,d).$$

d=0 时只有 r=L−1；1≤d<M 时最近游程后必须先出现0，故 0≤r≤min(L−1,d−1)，各状态可由 `1^L 0^(d-r) 1^r` 达到；d=M 时所有 L 种 r 均可达。由此得到上式。K24/L3 为64，69只是笛卡尔积上界。

对识别语言 `R={0,1}* 1^L {0,1}^{0,...,K-L}` 的输出 DFA，这些状态两两可区分。若 r_h>r_l，附加 `1^(L-r_h)0^(M-1)`：前者恰有尚未过期的新游程，后者没有新游程且旧游程过期。若 r 相同、d1<d2，附加 `0^(M-1-d1)` 使第一个年龄为 M−1、第二个过期。将到达前缀前填0可把它们放在同一足够晚的时刻；预热不改变区分论证。

因此给出了该识别 DFA 的最小状态数。**这不是所有风险优化器的下界。** 边输出的 Mealy 表示、仅保留未来代价信息的状态合并以及其他优化器不能直接套用这一 DFA 下界。没有把本状态计数宣称为已完成全球查新的首创。

## 2. 与 Cost-Regular 的逐项对应

| 当前问题 | 通用加权自动机/Cost-Regular |
|---|---|
| 观测0、1或未知 | 位置变量的域 `{0}`、`{1}` 或 `{0,1}` |
| 固定事件语言 | 有限自动机状态与事件输出 |
| 时间变化的标签系数 c_s | 随位置及转移状态变化的弧代价 |
| 所有相容轨迹 | 层展开图中满足变量域的路径 |
| 风险端点 | 最短/最长路径，加固定常数 |

Demassey、Pesant、Rousseau 的 [2006 原文第3节及脚注1](https://hanalog.ca/wp-content/uploads/2016/09/DPR_CostReg.pdf)已经允许位置、取值和自动机状态相关成本。当前递推是这个框架的实例。如果某实现仅接受非负成本，每层减去 `min(0,c_s)` 后再扣回已知偏移即可；负系数本身也不是区别。

通用基线独立构造 NFA `Sigma*1^L`，再以普通语言运算递推 `R_d = R_0 union (R_{d-1} Sigma)`，逐步确定化并用 Hopcroft 最小化。没有输入手写 `(r,d)` 图。最后每个时刻的接受标记用于计费，所有末状态均可终止，不能要求最后一个事件为真。

25组 K/L 的通用最小图均与手写图同构，150组数据长度/缺测布局计时均产生一致端点。[代码](../../src/urbanev_audit/regular_event_baseline.py)、[构建表](../../artifacts/summaries/shared_missing_events_ap1/compiler_benchmark.csv)。这排除了把旧后缀DP慢195倍当作相对一般自动机方法的新算法优势。

同类通用背景还包括 [Mohri 2002](https://cs.nyu.edu/~mohri/pub/jalc.pdf)、[Waga 2019](https://arxiv.org/abs/1906.12133)、[Ganardi等2018](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.STACS.2018.31)。它们的问题不完全相同，但通用路径计算和滑窗状态压缩均需据此定位。

## 3. 加权冲突代价恒等式

对模糊且 c_s≠0 的标签，令 y_s^- 为独立下界偏好；定义

$$\Gamma^- = \min_{z\in\mathcal Z}\sum_s |c_s|\mathbf1\{E_s(z)\ne y_s^-\}.$$

逐项减去独立最小代价：满足偏好时差为0，不满足时差为 |c_s|，因此

$$\ell_J=\ell_I+\Gamma^-/N,\qquad u_J=u_I-\Gamma^+/N.$$

独立宽度为 `sum_ambiguous |c_s|/N`。独立界跨零时，B新增严格优势当且仅当 `Gamma^-/N > -ell_I`；A 对称。等于零只给非严格比较。多个冲突核共用标签时，不能把各核的最低代价直接相加。

这些是既定优化目标的恒等式，不作为单独的新理论首创。它们把“有缺测”“有逻辑冲突”和“足以改变风险比较”区分开。

## 4. 完整两两标签关系的计算与 LP

对两个模糊事件，全未知置0同时实现 `(0,0)`，全置1同时实现 `(1,1)`；故两两关系只能额外排除 `(1,0)` 或 `(0,1)`，即蕴含/等价。

**有效关系构造。** 对窗口 i 中每个不含已知0的长度 L 候选游程 r，将其未知位设为1、其他未知位设为0，得到该游程的最小正见证。此游程向两边只会通过连续已知1延伸，记高段为 `[a_r,b_r]`。另一个模糊窗口 j 的事件在这个见证下为真，当且仅当

$$a_r-K+L\le j\le b_r-L+1.$$

其他全已知高段不能单独触发一个模糊窗口，否则该窗口下界已经是1。任意令 E_i=1 的补全至少实现一个候选游程，且事件单调。因此

$$E_i\Rightarrow E_j\iff
\max_{r\subset i}(a_r-K+L)\le j\le
\min_{r\subset i}(b_r-L+1).$$

这枚举了所有合法两两蕴含，不依赖预测器或是否产生正例。实现使用滑动候选游程及有序模糊原点，并通过区间树辅助变量压缩蕴含矩阵。每个 `e_i≤e_j` 都等价于源节点到包含目标叶的区间节点再到叶节点的约束；辅助变量消去后与显式LP相同。无关联标签独立求极值，未删除有作用的约束。[实现](../../src/urbanev_audit/event_relaxations.py)

在 `0≤e≤1` 及所有蕴含上优化线性损失得到有效外界，满足

$$[\ell_J,u_J]\subseteq[\ell_P,u_P]\subseteq[\ell_I,u_I].$$

构造式与全部补全的两两关系在小序列上直接核对。其作为专用关系生成方法的首次性尚未查明，不将“本次推导出”替换为“前人未提出”。

## 5. 高阶必要性不等于真实新增决策

底层四位全未知，K2/L1，标签分别为相邻两位的 OR。模式 `(0,1,0)` 两两可实现而整体不可实现。取 `a=(0,1,0)`、`b=(.5,.5,.5)`：独立界与两两LP界为 `[-.25,.75]`，完整轨迹界为 `[1/12,.75]`。

因此不能宣称两两LP普遍精确或完整优化理论上无用。但AP1自然数据中，即使完整DP在部分比较上继续缩窄区间，也没有带来两两LP之外的严格判向或候选集合改变。这是数学必要性与已测决策价值的区别。

## 6. 原点块与数值判断

P个连续原点使用P+K−1条底层记录。相邻原点块的标签支持可重叠；年度界独立求解，不把周界相加。跨站合并只在相容集合不额外耦合时按同一总窗口分母求和。

LP使用非负拉格朗日乘子构造箱约束对偶下界，并对求和残差向外舍入；相反目标给上界。DP对接近零的端点使用 `10^11` 整数网格求极值，加每窗口量化误差外包络。非近零端点使用保守浮点误差包络；严格定向阈值为1e−10。这是数值判断规则，不是统计显著性或性能晋级门。

本轮实际新增判断的余量明显大于数值误差，未把接近零的差异包装成研究效果。不是所有计算都做了形式化验证；独立MILP及语言/穷举对照是额外实现证据。
