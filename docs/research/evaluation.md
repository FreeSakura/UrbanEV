## 比较身份

同一排名必须对齐或披露目标单位、数据版本和清洗、区域粒度、预测原点及时间戳、历史长度、视野、输入可得时刻、训练/验证/测试范围、选择规则、后处理和聚合方式。

LOCAL 与 GLOBAL 信息轨道可以比较系统性能，但不能直接归因于单一模型结构。预训练系统应另外说明权重、预训练及推理条件；原生 point、Q0.5、监督适配分别登记。

## 末点与全路径

对 N 个原点、I 个区域及 H 步预测：

$$R_{terminal}(H)=\sqrt{\frac{1}{NI}\sum_{n,i}(\hat y_{n,H,i}-y_{n,H,i})^2},$$

$$R_{path}(H)=\sqrt{\frac{1}{NHI}\sum_{n,h,i}(\hat y_{n,h,i}-y_{n,h,i})^2}.$$

两者评价不同对象。raw 与 clip 也应独立命名，不能按成绩选择其中之一。H12 调用的切片不自动代表独立 H3 调用；缺失视野不得用另一视野冒充。

## 六折匹配约定

累计小时为 720/1464/2184/2928/3672/4344，训练占前 80%，测试取最后 10%，中间为验证。训练原点从 169 开始；O 输入为 `[o-168:o]`，可选 D 为 `[o-169:o-1]`，目标 `[o:o+H]`，主评分时刻 `o+H-1`。

每模型先计算每种子完整 24 格 RMSE 的等权平均，再平均种子指标；MAE 同理。缺格、混合合同、原点错配或键值身份不一致应拒绝汇总。每 H 的配对块 bootstrap 按正式配置执行，不将重叠窗口和区域当成独立实验重复。

全部注册训练完成后才按验证 raw 末点 RMSE 选择冻结 checkpoint；并列取较早者，不选最好种子，不用测试成绩挑后处理。残差模型的 epoch0 底座别名与直接模型的未训练初始化分别标记。

详细划分差异、上游核查与合成验证见[准备阶段记录](../reports/benchmark/EVALUATION_PREPARATION_20260914.md)。实际代码与任务预算见[正式合同](../reports/benchmark/MATCHED_SIX_FOLD_REPORT_20260914.md)。

## 如何表述结果

| 证据 | 可以支持的表述 |
|---|---|
| 开发/校准改善 | 指定开发设置的收益与代价 |
| 同合同完整比较 | 在列明的方法和任务中相应指标的排名，并报告不确定性 |
| 充分覆盖近期可信强基线 | 在明确数据版本、任务、日期和遗漏范围下讨论 SOTA |
| 合成机制或数学反例 | 给定假设的机制或边界结论 |

小于 1% 的收益不自动无效，MAE 有代价也不自动否定 RMSE 研究；应说明权衡。旧 1%/MAE/单元退化门只解释原协议 NO_GO，不作为新的全局要求。工程检查通过和合成机制成立均不能替代真实结果。
