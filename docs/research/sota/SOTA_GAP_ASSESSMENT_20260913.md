# 距离SOTA有多远：截至c2404cf的证据评估

回答时点：2026-09-13，研究快照c2404cf510efefa3b09ee62554187ee8ef117f65。本页记录本轮继续实验之前的判断，后续结果不能追溯改写此快照。

**目前无法诚实给出距离全球SOTA的单一百分比或预计轮数。** 我们已具备可检验的机制和真实开发实验，但尚缺稳定的方法优势与完整、最新、同协议的比较证据。“局部RMSE接近一个强参考”不等于接近完整基准SOTA。

## 可量化的局部差距

四H上，最新候选相对底座RMSE高0.077960%、MAE高0.290878%，只有一个种子同时超过底座。上一轮原交互的平均底座增益没有在新种子批次中保持；还没有稳定的局部方法胜出。

共同H3/H12上，候选RMSE比缓存native低0.166737%，MAE高13.724042%。若只以这个缓存参考的MAE为目标，我们需要从当前MAE再下降约12.067846%才追平：分母是当前方法MAE，与“比参考高13.724%”不是同一百分比。这个量是局部追平距离，不是全球SOTA距离。native的预训练和信息条件不同，不能据此归因方法效率。

若最终主张明确限定为RMSE最优，并不要求先追平MAE；MAE差距用于披露权衡，不能变成新的准入门。当前不能认定RMSE SOTA的关键仍是完整同协议强基线、稳定性与评价证据不足，而不是MAE未过一个人为阈值。

## 为什么不能直接算全球差距

1. 本地仍缺完整官方分割、全部所需预测时距及多时段结果；已有开发窗口反复曝光，不能声称独立确认。
2. 官方Table 3的TimeXer文献均值0.0924不能直接与本地局部0.111233相减排名。历史长度、原点、切分及数据版本需要匹配。[官方研究](https://doi.org/10.1038/s41597-025-04874-4)
3. 最新方法覆盖仍不充分，不能把Chronos缓存自动当作世界最优。2026年交通基础模型研究强调Chronos-2的重要强基线地位，但该预印本的跨数据结果不是本地同协议复现。[原文v2](https://arxiv.org/abs/2602.24238v2)
4. 新方法的跨种子稳定性、收益所处时距和机制必要性仍有反证。独立比较前不能把单个有利种子、共同支持或指标片段包装成总体胜出。

本次再次核查到DyConfuse-Net的出版商预览，报告UrbanEV MAE0.0155、MAPE9.680%，并描述不同的时间覆盖与预处理。完整归一化、选择和评分范围尚未逐项对齐；它必须保留为需要核查的强方法，既不能直接用0.0155计算我们的差距，也不能因为未复现便将其排除。[出版商预览](https://www.sciencedirect.com/science/article/abs/pii/S0378779626000581)

Urban-CSTPNet等近期工作继续保留在[基线登记](BASELINES.md)，本轮重访全文受到访问限制，没有补写已完成协议复现或穷尽查新。无维护完善的统一榜单证据，不等于不存在其他更强工作。

## 当前阶段与继续研究

当前更准确的定位是“方法假说筛选和开发证据积累阶段”。工程可复现性已改善，但不是尚差几个检查便能拿到SOTA；方法本身仍需要在强参照之上形成可重复收益。也不能因改善低于1%或MAE略差就宣判整个方向无价值。

下一轮检验纠错信号是否依赖底座样本内残差，而不能在训练内前向样本外残差重复出现。它针对当前稳定性瓶颈，不保证缩短到SOTA的时间。新实验仍需独立配置、固定预算与完整对照，结束后返回人工审核；不自动打开保护数据、租算力或调用新基础模型。
