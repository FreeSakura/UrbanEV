# 从分位点预测实验回到理论边界

本节解释当前实验该如何反馈研究路线；它不修改已经冻结的B2门槛，也不把开发结果改判为SOTA。

## 1. 稳健中点为什么可能明显劣于中位数

对九个十分位数，加上支持端点0和1，Q1–Q3的稳健均值中点可写为

$$p_*=0.05+0.1\sum_{i=1}^{9}q_i.\tag{F1}$$

因此，经过裁剪和排序的分位数都在[0,1]时，$p_*\in[0.05,0.95]$。这条规则无法产生接近0或1的点预测。它对未观测尾部保持最坏情况保护，但这种保护可能与实际尾部概率不匹配。

严格反例是$Y=0$几乎处处。九个真实分位数均为0，真实中位数和均值都为0，原生中位数预测的MSE为0；稳健中点却为0.05，MSE为0.0025、MAE为0.05。这没有反驳Q1–Q3，因为同样的有限分位信息也相容于在1处有0.1概率质量的分布，均值可到0.1。中点是在相容分布集合上的最坏后悔解，不是对每个真实分布都占优的解。

实验含义：稳健中点应保留为可解释的无训练对照，不能预先作为高精度点预测器。其真实误差必须由数据验证。

## 2. 降低MSE不自动意味着MAE不变

设一个条件分布的均值为$\mu$，取中位数$m$。平方风险从$m$移动到$m+\delta$的变化为

$$R_2(m+\delta)-R_2(m)=\delta^2-2\delta(\mu-m).\tag{F2}$$

当均值与中位数不同，朝均值的小幅移动可以降低MSE。另一方面，绝对损失以中位数为最优解，因此任何这种移动都不能保证改善MAE。对CDF为F的有界分布，绝对风险满足

$$R_1(m+\delta)-R_1(m)=\int_m^{m+\delta}(2F(u)-1)\,du\ge0.\tag{F3}$$

积分式在CDF跳点按几乎处处意义理解；有界性保证损失可积。若中位数不唯一，某些移动可能保持MAE相同。真实模型输出未必等于真实条件中位数，所以这不是对模型间比较的“不可能定理”；它说明即使分位模型完全正确，MSE与MAE也可能存在目标冲突。

本轮使用同一具名系统的一组点预测同时计算RMSE与MAE。不会为RMSE临时换用适配头、为MAE换回原生中位数，然后把两项最优值拼成一个系统。联合门未通过时仍记录NO_GO。

## 3. 同信息ridge为何是必要对照

单纯形头和全分位ridge都使用相同增广分位设计$X$、先验$w_0$、训练标签以及验证选择网格。二者区别是前者加入非负与和为1的约束，后者没有该约束。若两者表现接近，即使它们都优于原生点输出，也不能把收益归因于单纯形约束。

实验需要分别回答：使用更多分位信息是否有用；普通线性校准是否已足够；约束是否带来额外泛化收益。当前数据的选择与比较范围仅为开发区，不能由某一个验证赢家推出跨折或独立时间段结论。

## 4. 对后续研究的约束

若B2对两个基础模型均未通过，就停止把该单纯形头扩展为SOTA主方法。可以保留分位校准为强基线，并在新的协议中研究误差结构、尾部建模或明确的RMSE–MAE权衡。新的目标或约束需要新的协议与未用于该选择的验证证据；不得在本轮数据上修改门槛后重新宣布成功。
