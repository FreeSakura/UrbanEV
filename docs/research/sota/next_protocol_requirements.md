## 顺序与核心问题

先完成本次信息资格与覆盖登记，再优先验证现有双风险方向能否转为足量的有限步长收益，之后开展固定预算的信息族筛选。时长是优先线索，而非唯一可用信息。若有限步长失败，应回到表征、条件分布或其他信息的假设，不再无界提高旧求解器精度。

下一方法要回答：仅根据预测前可用信息和较早校准数据，能否选择一段移动范围，既避免大量预测越过真实值后的MAE增损，又保留至少1%的宏RMSE收益。方向导数没有提供这个范围；三分类概率也没有提供完整条件CDF的一致误差保证。

## 后续公平信息族筛选

固定基础信息集I0，包括占用历史、明确登记的日历与基础预测。对每个候选族Z，计划三种角色：基础组I0、单族增广I0+Z，以及在时长D存在时比较I0+D与I0+D+Z。对duration本身只做前两类，避免重复比较。

| 信息族 | 单族比较要排除的混杂 | 时长条件下的附加问题 |
|---|---|---|
| 电价 | 与日历/区域类型共变、单位冲突、未来费率未公布 | 是否仍有条件增量，而非重编码活动时段 |
| 服务费 | 与电价捆绑、固定站点类型效应 | 是否补充或重复时长/电价信息；不预先把电价和服务费合并 |
| 天气 | 未来实况泄露、两个观测站复制成大量伪独立样本 | 是否改变条件分布和损失符号，而非只解释均值 |
| 容量与静态几何量 | 目标归一化已经使用容量、快照时点与站/区层级混淆 | 显式容量特征是否改善有限模型共享与异方差建模 |
| 空间/POI | 静态相关性等同机制、事后POI快照、坐标系不明确 | 状态或交互增量是否超出时长和自身历史；不是重开旧分组搜索 |
| 电量及派生版本 | 当作独立电表、功率构成未区分、正则随维度改变 | 区域总时长之外是否保留功率加权构成信息；两种电量估计分别标明来源 |
| 时长 | 重复特征和预测差参数化、端点与发布时间 | 保持当前线索与历史失败分别记录，不先验宣布其独占有效信息 |

所有比较统一目标、原点、视野、样本权重、预测时可得性和拟合/选择预算。先筛选研究优先级，不能将单族失败解释成排除全部交互；不将所有变量一次性拼接后把收益归给某个字段。
