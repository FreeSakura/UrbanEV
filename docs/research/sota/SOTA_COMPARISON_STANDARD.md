# SOTA比较与研究声明规则

生效：2026-09-13，前瞻性替代旧内部筛选门作为当前研究总规则。**没有一个适用于所有学科、数据集和指标的国际SOTA认证阈值。** 本项目采用领域原始基准、明确版本的评价实现和权威学术报告规范来约束声明；不把本项目选择冒充国际标准。

## 1. 三类依据分别标明

| 层级 | 来源与含义 | 不能由此推导什么 |
|---|---|---|
| 领域基准 | [UrbanEV数据论文](https://doi.org/10.1038/s41597-025-04874-4)、[官方代码](https://github.com/IntelligentSystemsLab/UrbanEV)、[数据版本](https://doi.org/10.5061/dryad.np5hqc04z)：规定或示范任务、数据和实验 | 论文中的最佳方法不是永久榜首；当前代码不自动等于论文历史运行 |
| 通行学术报告要求 | [NeurIPS Paper Checklist](https://nips.cc/public/guides/PaperChecklist)：披露设置、复现方式、恰当的不确定性和资源口径 | 没有规定普遍的1%收益、固定三种子或所有指标同时最优 |
| 本项目明确选择 | 主研究指标RMSE，完整报告MAE、成本与局限；每轮人工审核；任何新实验提前声明任务、选择规则与预算 | 这些选择不是官方认证或世界统一规则，不能据此宣判其他论文无效 |

研究价值与排行榜名次分开。权威评审也评价方法新意、技术质量和潜在影响；未超过SOTA本身不充分否定研究价值。[CVPR评审指南的明确说明](https://cvpr.thecvf.com/Conferences/2025/ReviewerGuidelines)

## 2. 取消普遍适用的个人数值门

未来不再以“RMSE至少降低1%”“MAE必须零恶化”“任一单元RMSE恶化不能超过1%”作为通用SOTA或候选继续研究的必要条件。小于1%的真实改善也可以值得研究；MAE存在代价时应诚实报告多指标权衡，不能泛称全面领先。若特定应用需要非劣约束，应说明应用依据并另行预设，不能追认成国际共识。

旧配置、原始结果、已消费claim和NO_GO保持不变。它们仍准确表示“在当时内部协议下没有继续执行”，不会被重算成新赢家；本次调整也不授权重新搜索旧校准网格。历史结果的科学解释和SOTA证据另列于[成果地图](RESEARCH_INDEX.md)。

## 3. 每条优越性声明需要的比较身份

同一条排名至少明确：目标变量及单位、数据版本/清洗、空间粒度、预测原点与目标时间、预测视野、上下文和协变量的可用时刻、训练/验证/测试范围、输出后处理、指标聚合与模型选择方式。不同预训练数据和计算预算可以比较，但应明确预算/信息条件，并用适当对照支撑方法归因，不能伪装为严格同资源试验。

特别将两种目标分开：

$$R_{\mathrm{terminal}}(H)=\sqrt{\frac{1}{NI}\sum_{n,i}(\hat y_{n,H,i}-y_{n,H,i})^2},$$

$$R_{\mathrm{path}}(H)=\sqrt{\frac{1}{NHI}\sum_{n,h=1}^{H}\sum_i(\hat y_{n,h,i}-y_{n,h,i})^2}.$$

N为原点数，I为区域数。两者不是同一指标。本轮发现指定上游代码采用前者，而旧开发配置采用后者；不能因都叫“H小时RMSE”就比较。未经版本、输入和原点桥接，不将旧局部0.07左右数值与论文表格0.09左右数值判作胜负。[源码与探针](BENCHMARK_ALIGNMENT_REPORT_20260913.md)

## 4. 分开报告五个问题

1. **点估计排名**：在明确的测试集合、指标及对照集合内，哪个结果更低。小数差距必须与报告精度相称。
2. **不确定性**：差异有多稳定。说明随机初始化、时段抽样、数据划分各自的变异；确定性模型不重复同一次拟合充当独立种子。
3. **统计支持**：若使用检验/区间，说明方法、相关性假设和多重比较。重叠时间窗和区域不是自动独立样本；不能把大量窗口数当独立重复数。p<0.05也不是万能SOTA认证。
4. **实际价值**：收益相对于训练、推理、输入采集成本是否有价值，有哪些指标或区域代价。阈值如需使用，应有任务理由。
5. **新颖性和机制**：即使榜首也需说明相对已有工作的新贡献；同信息HMM等价或普通校准解释的收益，不能仅改名为新理论。

## 5. 合适的声明形式

| 已有证据 | 可以表述 | 不可表述 |
|---|---|---|
| 开发/校准窗口改善 | 某开发设置中的观测收益与代价 | 官方测试SOTA |
| 同协议完整比较中某指标最低，差异支持有限 | 在已比较方法中点估计最低，并报告不确定性 | 已证明普遍显著优于全部方法 |
| 同协议最新可信强基线覆盖充分，完整结果支持 | 限定数据版本、任务、指标和比较日期的SOTA主张，并披露遗漏与限制 | 国际机构认证、所有指标/所有场景全面领先 |
| 人工机制或不可识别性反例 | 给定模型假设下的机制/边界结论 | UrbanEV真实预测提升 |

不存在“先过一个个人门，再自动获得SOTA”的布尔开关。排行榜、公开论文与复现均是证据来源，作者的“SOTA”措辞或期刊级别也不代替协议核验。没有代码的已发表强方法不自动被排除；应给出公开结果及可比性限制，必要时解释复现缺口。
