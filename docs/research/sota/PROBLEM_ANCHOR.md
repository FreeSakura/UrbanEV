# 研究目标锚点

- 核心问题：在UrbanEV标准多变量小时占用率预测任务上突破可复现强基线，以RMSE为主指标、MAE为共同报告指标。
- 必须解决的瓶颈：现有模型组合只有有限开发收益，尚未建立可比较的SOTA；需要找到强基线未捕获且预测原点可用的增量信息，并用统一任务验证。
- 非目标：不以审计论文、事件Brier改进、改名或人工遮挡收益替代标准预测进展；不预先声称新架构有效。
- 约束：275区域、小时占用率、3/6/9/12小时视野；公开数据许可和既有数据边界保留；现有约8GB显存，先测资源再扩展；不自动增加付费算力。
- 成功条件：在冻结任务与匹配输入/划分/统计口径下，优于纳入比较的最强可复现模型；公开完整种子、视野、逐折结果、成本和机制消融，并为独立确认保留明确边界。达到内部门槛不自动等于全球SOTA。
