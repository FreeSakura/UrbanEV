# 双方向试验：区域选择失效与观测模型优化混杂

2026-09-10 · FreeSakura

## 结论

两个方向均已实际尝试，候选机制均未获得通过依据，但并非所有信息都无用。**区域方向保留简单原始相关分组，停止当前残差引导交换；观测方向保留历史时长的增量信息线索，暂不把算子结构作为有效创新。**

所有结果来自既有首折开发区：训练边界576、验证576–647，验证只有3天且之前已有曝光。没有读取最终测试或保护数据，没有SOTA或独立确认结论。两个方向互不替代，先前单纯形头NO_GO不变。

## 1. 两条路线如何独立尝试

A使用固定Chronos-2权重、168小时历史及H3/H12，比较完整275区域与七种K32分组。所有区域恰好出现一次；八组32区域加一组19区域。随机交换与残差引导交换都从同一残差分组出发，各24次候选交换；每次对两个受影响组、四个训练原点及两个视野计算交换前后的原始MSE。两种搜索均为384次后端API调用、24576个通道任务，不缓存搜索调用以制造不对称预算。只在训练联合损失下降时接受交换。

原始相关与残差相关使用相同288–575行。残差来自自身滞后1/2/24/48/168与日历谐波的滚动样本外ridge，但本次相关代理仅为同刻绝对Pearson，不是已识别因果图或完整的滞后条件信息量。地理控制是经纬度排序分块，不是最优地理聚类。为匹配计算，19区域尾组未参与两种交换搜索。

A的新脚本显式向Chronos传入九个独立组。基础适配器元数据中的`variate_chunking=false`指后端不自动拆分每个输入任务，不表示本实验仍使用一个275区域联合上下文；外层显式分组的语义以新协议和实际group记录为准。

B使用相同168小时占用历史，并把时长输入再滞后一行，确保最晚时长索引为origin−2。为使首段历史完整，训练原点从169开始、步长3；H3/H12的最后训练目标都为573。比较占用输入、直接拼接时长、无结构多任务，以及软观测结构模型。使用三个种子、两个视野、六个系统，共36次训练；相同336维输入层、32隐藏宽度、每小时四个潜在时间格和匹配输出规模。

算子模型设有界占用路径O与A=O·sigmoid(a)，以O末端预测快照、A的格内平均预测标准化时长；自由多任务对照采用独立有界A。共同损失为占用MSE、固定权重0.1的时长辅助项（仅多任务系统）及权重0.001的共同路径平滑。释放数据仅通过软损失拟合，不要求观测快照大于同一行累计时长。

时长左/右两种端点解释分别运行，不根据验证分数挑选“真实”物理解释。未来格上的潜状态不当作已恢复真值。

## 2. A：候选选择机制失败，简单分组有线索

下表为H3/H12等权宏平均；均报告同一原始Q0.5在[0,1]裁剪后的RMSE/MAE。原始分数见JSON。

| 系统 | 宏RMSE | 宏MAE |
|---|---:|---:|
| full275 | 0.07069936 | 0.04099575 |
| contiguous32 | 0.07093077 | 0.04117575 |
| random32 | 0.07081383 | 0.04115296 |
| geographic32 | 0.07082646 | 0.04108217 |
| raw_correlation32 | 0.06976947 | 0.04068305 |
| residual32 | 0.07100607 | 0.04117647 |
| random_swap32 | 0.07089943 | 0.04109917 |
| utility_swap32 | 0.07097649 | 0.04108757 |

残差引导交换比最强匹配控制raw_correlation32的RMSE差1.7300%，也没有满足MAE非劣化；H12的RMSE退化为2.5021%，超过单格1%限制，故原定门为**NO_GO**。它还比完整275参考差约0.3920%。随机搜索接受13次交换，引导搜索接受16次；接受更多训练损失改进不等于更好的开发预测。

但raw_correlation32相对完整275参考的宏RMSE下降1.3153%，MAE下降0.7627%。这是分组可能有用的开发线索，不是本次新交换机制的成功，也不是新的通道聚类首创性或SOTA证据。

**明确问题：**

- 本次残差代理比原始相关弱，可能丢掉了冻结骨干实际利用的共同周期信息；这是待验证解释，尚未建立因果归因。
- 仅四个训练探针原点，局部交换的训练效用未转移到开发集；不能据此断言所有训练期效用选择都无效。
- 只测试一个骨干、K32和一个残差定义，尾组冻结，未覆盖预算曲线与更充分的训练探针。
- 计时发生在研究工作环境中，不能作为独立部署效率排行榜；未证明理论注意力规模减少转化为端到端提速。

下一步不扩大这个失败准则的搜索。先把简单相关分组作为必须击败的基线；若研究新的条件准则，应使用新协议，并证明增益不是额外查询预算带来的。

## 3. B：先发现优化不足，再检查结构收益

duration/capacity按论文声明的桩·小时口径解释，648×275值均有限且落在[0,1]。这个检查只排除明显量纲/数值错误，没有证实端点归属、实时发布可用性和独立物理真值，因此物理识别/部署主张仍为**NOT_QUALIFIED**。

初始36次神经训练全部在第20轮取得最好分数，均触及上限。原始信息门的计算结果是GO_PILOT_ONLY（拼接时长相对占用输入RMSE下降2.5588%），但这是弱且尚未充分优化的基线比较，不能当作成熟结果。左右算子相对最强同输入控制仅改善0.4410%/0.2471%，均未过1%门。

为明确优化混杂，保留全部v1结果，另做后验诊断：所有36个组合从各自v1检查点追加最多80轮，改用GPU向量化批处理、重新初始化AdamW状态与公共规则的新shuffle种子，数据、架构、损失及学习率不变。不能把它称为原训练轨迹的精确续跑，也不能把它当作独立确认。原v1门不重写。

| 系统 | v1 RMSE | v1 MAE | 追加优化 RMSE | 追加优化 MAE |
|---|---:|---:|---:|---:|
| occupancy_only | 0.13663274 | 0.10722326 | 0.07578981 | 0.04915804 |
| duration_concat | 0.13313659 | 0.10463948 | 0.07362309 | 0.04741852 |
| free_left | 0.13542118 | 0.10693250 | 0.07395226 | 0.04780875 |
| operator_left | 0.13254948 | 0.10409139 | 0.07363560 | 0.04744485 |
| free_right | 0.13571272 | 0.10719919 | 0.07398995 | 0.04783160 |
| operator_right | 0.13280756 | 0.10433455 | 0.07363741 | 0.04746303 |

追加优化后，直接拼接时长相对占用输入的宏RMSE下降2.8588%、MAE下降3.5386%，保留了信息增量线索。但左右算子仍分别比直接拼接差约0.0170%和0.0195%的RMSE，MAE也略差。**没有观察到算子结构的额外优势。**

追加阶段29次触及80轮上限，其中7次仍在最后一轮最好，故不能宣称全部模型已经充分收敛。明显欠拟合已缓解，剩余优化和模型设计限制仍需保留。

## 4. B的简单基线检查

另行运行固定λ=0.01的残差ridge与朴素预测，标为后验优化诊断，不替换v1门。它使用同样训练原点与验证窗口，所有标准化参数仅由训练样本拟合。

占用ridge的宏RMSE/MAE为0.07370265/0.04673582；加入滞后时长后为0.07126149/0.04473384，RMSE下降3.3122%。它比本次追加优化后的神经系统仍强，进一步说明弱神经对照不能充当有利的论文基线。该对比还涉及新增输入维度，不能单独排除所有有限模型/正则效应，故仍只是开发线索。

**明确问题：**

- 优化预算是v1的重要混杂因素；不应把优化速度差异包装成观测物理优势。
- 在补充优化后，算子仍未优于同输入拼接控制；结构价值未建立，不能只展示相对占用输入的提升。
- 左右端点与真实可用时间未完全证实；良好误差也不能证明潜在主动/非主动状态被正确识别。
- 同一已曝光开发窗上的优化诊断不是新验证集，不能据此改称正式通过或SOTA。

后续优先把时长输入交给可信的强基线检验，并完成时间语义资格检查。暂不扩大潜状态模型、调整物理约束强度或追加模块来追逐此开发窗。

## 5. 失败分层与保留事项

| 层次 | A区域路线 | B观测路线 |
|---|---|---|
| 数据/身份 | 相同前缀及冻结参考已核对 | 数值范围通过，物理时间语义未定 |
| 实现与预算 | 匹配384调用与64通道/调用 | 参数规模、数据与种子匹配；补充优化另列 |
| 优化 | 24个局部交换，不声称最优 | 初始预算不足，后续缓解但未完全排除 |
| 信息线索 | 原始相关分组优于全区域参考 | 滞后时长在多个有限模型中有开发增益 |
| 新机制 | 当前残差引导交换NO_GO | 算子结构额外收益未成立 |
| 成果范围 | 一个骨干、首折、K32 | 首折、三个种子、两种对齐假设 |

失败意味着当前具体实现不值得直接扩大，不代表所有分组或所有观测模型在任何数据上都无效。应保留正面信息线索，但不为已有机制调整门槛或改判旧失败。
