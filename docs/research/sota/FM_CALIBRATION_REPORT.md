# 冻结基础模型的分位点预测适配：首折开发验证报告

2026-09-09 · FreeSakura

## 结论与研究决策

在Chronos-2与TimesFM-3的275区域联合预测上完成了既定H3/H12开发验证。两个骨干的单纯形头均未通过推进门，**停止将该头扩展为SOTA主方法**。研究项目继续推进，完整基线与新的机制问题保留；原生点预测、分位校准和同信息ridge作为后续必须面对的对照。

相对原始Q0.5，单纯形头的宏RMSE分别下降2.1819%和2.3726%，但宏MAE分别上升1.6199%和2.5496%。相对最强同信息ridge，Chronos-2上的RMSE增益为−0.003855%，TimesFM-3上为+0.003010%，远未达到预设1%，且MAE均略劣。不能把相对原始点输出的收益归因于单纯形约束。

## 1. 实际完成的范围

数据为既有UrbanEV小时占用率：648小时×275区域，2022-09-01至2022-09-27。训练截止索引576（不含），验证为576–647；测试段未读取。原始占用数/区域容量的float32构造经限定前缀重算，与准备好的CSV完全一致。归一化分母不是模型预测统计量。

每个骨干执行H3和H12两种完整未来序列预测。H3有406个训练窗口、70个验证窗口；H12为397和61。每个骨干共934个原点—视野任务，两骨干共1868个；这些重叠窗口不是独立样本。验证只覆盖3天，且用于正则选择，所以结果是开发选择证据，不是独立确认、六折最终成绩或SOTA。

骨干权重冻结，头部为确定性凸优化；没有把重复同一个拟合过程算作多种子证据。3/6/9/12全视野、六折、收敛TimeXer等强训练基线和独立确认仍未完成。

## 2. 基础模型身份与推理语义

Chronos-2复用已锁定的2.2.2包与权重revision `29ec3766d36d6f73f0696f85560a422f50e8498c`。本轮是新的校准协议，不重新判定旧teacher门。软件包源码文件SHA、依赖版本及模型文件SHA随附回执；先前文献核对的较新源码仅作语义参考，不冒充本次执行版本。

TimesFM-3使用3.0.1代码revision `8cb7eda91c2b416b37e99a979afc50f2a18e1791`，权重revision `43046b85ec22d584a13f8098c2ed39c889e129c2`。官方`TimesFM3Evaluator`会把高维变量自动拆成最多32个变量一组，因此本次选择`TimesFM3Forecaster`，关闭排序、正值修正与对称平均，保留原始Q0.5和原始九分位。它是本项目注册的full-275操作配置，不是官方评测包装器的完整默认配方；不能据此声称覆盖TimesFM-3的所有最佳配置。[固定版本源码](https://github.com/google-research/timesfm/blob/8cb7eda91c2b416b37e99a979afc50f2a18e1791/src/timesfm3/torch/evaluator.py)

每次只向模型传入同一原点的168×275历史矩阵，无跨原点学习、无未来协变量、无区域拆组。实际前向记录中，Chronos-2为275×168且group数为1；TimesFM-3的Transformer输入为1×275×8×1280。内部padding不是新增未来观测。

在RTX 4060 Laptop 8GB上，Chronos-2记录的GPU峰值分配为738,029,568字节（约0.687 GiB），TimesFM-3为1,459,303,424字节（约1.359 GiB）。首个H3调用分别约0.773秒和0.953秒；紧随的H12调用约0.312秒和0.680秒。这里只是单原点可行性profile，有冷启动差异，不是部署延迟排行榜。

TimesFM-3权重采用独立的非商业、非生产许可，本次用于本地研究。公开包仅含代码、汇总和哈希，不发布权重或拟合后的头部参数。预训练是否与UrbanEV重叠仍未知，不声称无污染的zero-shot确认。[模型卡与许可](https://huggingface.co/google/timesfm-3.0-pytorch)

## 3. 同标签、同信息的对照

分位网格固定为0.1至0.9。原始Q0.5单独保留；修复分位先clip到[0,1]再单调排序，并记录修复率。中点、ridge和单纯形头共享该修复设计。bias/affine使用相同训练标签；全分位ridge与单纯形头共享全部分位信息、先验及正则网格，只在是否约束权重非负且和为1上不同。

所有正则候选为0.001/0.01/0.1，由验证clipped RMSE选择。全部已执行simplex候选达到≤1e−8的投影梯度残差；最终两种适配头在全部设置中均选择0.001。每个base/fold/H只有一个跨区域、跨步共享头。测试不参与选择，同一具名系统的一组点输出同时计算RMSE和MAE。

## 5. 实验反哺理论

九个十分位数的稳健中点必落在[0.05,0.95]，即使所有预测分位都为0，也输出0.05。这种对未知尾部的最坏情况保护可能引入明显偏差。其minimax正确性不蕴含对每个真实分布的点误差优越性。

另一个边界是MSE与MAE：对同一分布，均值最小化平方损失，中位数最小化绝对损失。移动点预测以降低MSE，可能增加MAE。当前结果不能通过为不同指标临时切换预测来“同时获胜”。详细推导和反例见[理论反馈](FM_CALIBRATION_THEORY_FEEDBACK.md)。本轮门槛保持原值。
