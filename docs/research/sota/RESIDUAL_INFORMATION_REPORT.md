这属于第三折训练内部筛选，不能与逐小时标准验证成绩直接混排。只准备1747行；第三折验证[1747,1966)与测试[1966,2184)均未读取。历史折的测试时间进入扩展训练已披露，也没有全局盲测或SOTA声明。

## 2. 非零步长为什么失败

原生Chronos宏RMSE=0.08144018，MAE=0.04312105。以下列出非零步长，防止回退后相同的分数掩盖失败。

正交时长在α=0.5时RMSE改善1.4844%，MAE却恶化1.2797%；α=1时RMSE改善1.6783%，MAE恶化4.6883%。α=0.25的MAE也恶化0.2888%。因此它们均不满足预先设置的MAE条件，不能只挑RMSE改善宣布通过。完整bias、重复和错配对照也保存在JSON。

全部α=0导致所有系统与原生模型完全重合。由此得到的[0,0]增益重采样区间是同一预测相减的恒等结果，不是模型有效、确定无害或高置信非劣的证据。信息门与结构门都为false。

## 3. 理论获得了什么反馈

36组已用留出预测的风险差核验满足ΔR=2a−b，最大浮点误差3.361e-18。OLS训练交叉矩接近机器精度，说明线性投影执行正确，不代表留出集或完整条件空间也正交。

正交时长六个单元的误差方向矩a均为正，但单位步长在第一个H3单元出现负的未裁剪平方收益；不同窗口的经验a/b不同。该诊断说明相关性、方向二阶矩和步长需要共同判断，不能把a>0当作固定α=1的保证。

这里诊断的δ是“占用残差头＋时长残差头”的总修正方向，并非孤立的时长分量。因此a>0不能证明收益由时长独立提供；时长增量必须通过相对占用头的控制比较判断，本轮注册信息门仍失败。

裁剪MAE在零点的平均右导数为-0.000430430。它为负，说明在这些已用样本上存在足够小的正步长可降低MAE；不保证同时达到1%RMSE门或未来有效。导数与ε=10⁻⁷有限差分的最大差约1.228e-10。该ε仅用于数值核验，未纳入候选步长进行选择或过门，也未回写失败门。

由此新增推导：裁剪MAE沿固定方向是分段线性的，断点来自预测跨越0、真实Y、1；可行集不必连通。每个断点区间内的宏RMSE是凸函数，因此下一协议可以预先注册逐区间可行性与一维最小化，而非事后缩小网格。连续步长求解本轮尚未运行。

## 4. 失败边界与后续停止条件

- 当前注册修正和离散步长集合：NO_GO，第三折验证保持未打开。
- 信息边界：没有证明时长完全无信息；不能把所有回退分数相同解释为时长和占用等价。
- 结构边界：原始D拼接在非零步长下与正交化接近，未建立可发表的结构优势；残差化还额外拟合OLS投影，不能称参数成本完全相同。
- 理论边界：总体ridge非负收益不保证有限样本、宏RMSE或MAE改善。训练内选择后的块区间只是描述性诊断。
- 下一版必须另行冻结连续步长选择规则，并留出新的训练内评价段；不能继续拿当前三个窗口反复优化再称新证据。
- 时长端点、实际发布时间与预处理因果性仍未知；无线上或潜状态识别结论。
