# AP1 论文主张锁定 v1

状态：**已按AP1结果锁定工作稿主张；独立算法首创与高阶优化的额外模型选择价值均撤回。** 锁定的是当前可写的证据范围，不表示已确认期刊录用或投稿成熟度。

工作题目：**共享缺测下持续事件预测比较的可识别性层次：低阶约束的作用与完整轨迹优化的边界**。

## 核心主张

> 对固定有限面板中的持续事件预测，共享底层缺测产生三级评价问题：逐标签独立不确定性、两两逻辑一致性、完整轨迹一致性。加权冲突代价解释了端点收缩是否足以跨越比较余量。在本研究预设新年份、阈值与预测器设置中，两两一致性取得了全部观察到的新增严格判断和候选集合变化；完整轨迹优化虽进一步缩窄部分区间，却未增加严格判向。这支持分层评价及适用边界分析，而不支持宣称高阶求解普遍改善模型选择。

## 明确排除

- 不写“提出了新的通用高效自动机优化算法”“相比已有方法快195倍”。195倍只针对旧后缀实现，不能代表最近邻通用算法。
- 不写“完整轨迹一致性带来不可替代的真实模型选择优势”。AP1未观察到相对两两LP的新增决策。
- 不写“在两个领域均改善选择”“在主设置稳定复现”。新增判断只在北京预设K72补充设置；K24与功率没有新增。
- 不写“整体排行榜改善”“未来部署/经济收益提升”“恢复缺失真值”“95%总体置信保证”。
- 不把两个含有相同缺失位的周块或同期多个站点当作独立重复；年度站点结果与周级结果不合成一个复现次数。

## 论文路线决定

**继续，但仅按“评价层次与适用边界”方法工作稿组织；停止以专用高阶DP性能或不可替代选择收益为主线的扩张。** 新年份出现了分散于5个时间块的回顾性候选变化，具有有限问题价值；但发生率低、主设置和功率负结果，以及通用框架覆盖核心计算，都限制了贡献强度。

现有证据不足以锁定“已经达到JCR Q2投稿质量”。未决的是此评价对象相对最近邻工作是否有足够重要的新问题和方法贡献，以及既定保留年份的复制能否支持工作稿范围。不能用堆模型、换阈值或扩大年份直到正例出现来解决这一问题。

AP2保留范围未使用。后续若执行，只验证这里已锁定的有限表述，不恢复被撤回的算法首创主张，也不先把后续范围当作已确认成功。
