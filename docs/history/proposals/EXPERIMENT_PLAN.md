# 实验执行计划

2026-09-09。主假说：冻结多变量基础模型的有界分位信息，通过一个共享MSE适配头可改善UrbanEV RMSE。不是已成立结论。

## 主张与反证

| 主张 | 最小证据 | 必须排除的解释 |
|---|---|---|
| C1：适配比原生中位数更适合平方损失任务 | 与原生输出、修复后中位数、中点、bias-only、affine同标签比较 | 只是更换输出命名、裁剪、排序或普通偏差校准 |
| C2：有界约束或先验有实际作用 | 与使用相同全部分位信息的无单纯形ridge控制比较 | 只是多用了分位特征或多了参数 |

## B1：基础模型可行性与身份

固定Chronos-2与TimesFM-3的代码、权重revision及环境。每个任务为同一原点的275区域×168历史步，输出完整H步九分位；不同原点不得混成变量组。先对一个训练原点生成预测，记录原生点语义、shape、耗时、峰值显存和修复率。batch降至1仍OOM则记录不可行/CPU成本，不静默拆变量组。

权重预训练数据与UrbanEV可能重叠的程度必须登记；unknown不等于无污染。TimesFM-3权重许可与代码许可分开记录。未锁权重或未通过单原点核查，不运行全量缓存，不报告该模型完成。

## B2：开发区最小机制验证

fold1/H3先做smoke，路线门固定为fold1的H3和H12。训练前缀截止576小时，验证前缀截止648小时；所有目标都必须完整落在所属区间。每个基础模型/fold/H各自拟合一个共享头，将原点、未来步和区域展平成样本，不跨fold拟合。

预测系统固定为：原生中位数；修复后中位数；有界中点；原生中位数+bias；原生中位数的二参数affine；中点affine；全分位ridge；单纯形头。bias/affine/ridge和单纯形头使用完全相同训练标签。头部强度网格为0.001/0.01/0.1，仅由验证clipped RMSE选择；投影梯度残差须≤1e-8，否则标记未收敛。

全分位ridge是Q4移除单纯形约束后的同信息控制，使用同一w0与正则网格。有限分位插值或尾部假设不得伪装成真实均值。排序只用于明示的替代分位系统，原生中位数必须单独保留。

内部推进门：H3/H12等权宏RMSE相对最强简单/同信息控制至少下降1%，宏MAE不劣化，任一单格RMSE不得恶化超过1%。失败则停止扩建该头，公开负结果；不在看到失败后改阈值。确定性凸头不靠重复seed充当独立实验。

## B3：冻结完整比较

方法、输出泛函和搜索预算冻结后执行六折×四视野。随机训练模型使用42/43/44；确定性头按基础模型随机性分别记录。每格指标覆盖所有原点、H步与275区域；先形成每种子的24格等权宏指标，再报告种子均值/标准差。原始和裁剪分数分列。

报告配对误差及时间依赖；不能把重叠预测窗口当独立样本计算普通i.i.d.标准误。跨折结果、模型随机性和时间块不确定性分开解释。任何显著性主张须在另行冻结的推断协议下给出，不由1%门自动推出。

SOTA声明还需要最新可比强基线的完整清单与协议桥接。旧内部结果不等于新的盲测；新的独立时间/来源确认范围仍未建立。
