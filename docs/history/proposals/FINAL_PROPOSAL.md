# 研究方案：冻结多变量基础模型的有界分位点预测适配

## Problem Anchor
# 研究目标锚点

- 核心问题：在UrbanEV标准多变量小时占用率预测任务上突破可复现强基线，以RMSE为主指标、MAE为共同报告指标。
- 必须解决的瓶颈：现有模型组合只有有限开发收益，尚未建立可比较的SOTA；需要找到强基线未捕获且预测原点可用的增量信息，并用统一任务验证。
- 非目标：不以审计论文、事件Brier改进、改名或人工遮挡收益替代标准预测进展；不预先声称新架构有效。
- 约束：275区域、小时占用率、3/6/9/12小时视野；公开数据许可和既有数据边界保留；现有约8GB显存，先测资源再扩展；不自动增加付费算力。
- 成功条件：在冻结任务与匹配输入/划分/统计口径下，优于纳入比较的最强可复现模型；公开完整种子、视野、逐折结果、成本和机制消融，并为独立确认保留明确边界。达到内部门槛不自动等于全球SOTA。


## 技术缺口与路线选择

经源码核查，Chronos-2 predict_quantiles的mean返回值是0.5分位，TimesFM-3默认forecast也为中位数。该事实给出比“新静态图有用”更直接的问题：基础模型默认点泛函是否适合UrbanEV的RMSE目标。不能由中位数的RMSE不理想推出基础模型无用，也不能仅切换接口字段就解决均值问题。源版本及链接见POINT_FORECAST_CONTRACT.md。

主研究假说改为：冻结多变量基础模型的分位输出，使用一个有界、正则化、训练期拟合的MSE点预测头，能否比原生中位数和简单校准更好地利用其预测信息。单一贡献候选是“目标泛函适配”；跨区域创新注意力降为后续机制探针，不与本主线合并，也不新增蒸馏教师或另一个路由器。

## 主方法的最小定义

基础模型提供每原点、区域、未来步的m个分位。先报告越界/交叉率，再统一clip[0,1]和单调排序得到q；增广x=(0,q1,...,qm,1)。给定分位网格tau，支持约束给出均值区间及稳健中点，完整Q1–Q4证明见QUANTILE_MEAN_THEORY.md。w0取对应梯形积分权重。用训练区样本最小化mean((Xw-y)^2)+lambda*||w-w0||²，约束w>=0,sum(w)=1。每个H配置一个全区域、全H步共享的m+2权重头，不能逐站自由拟合。lambda在{0.001,0.01,0.1}中由验证RMSE选择；头部唯一解存在，数值求解需达到预注册投影梯度残差1e-8，未收敛则不进入结果表。

冻结基础模型只用各原点之前168小时上下文；训练标签窗口完整落在训练期。基础模型预训练来源仍可能与UrbanEV重叠，因此不宣称零样本无预训练污染；记录model revision、训练数据披露和潜在重叠。MSE头增加的是任务训练数据使用权，必须单独标记adapted，不与纯zero-shot混为同一预算。

主榜每个具名系统固定一组点预测同时计算RMSE/MAE。原生中位数、稳健中点、简单偏差校准、单纯形头各自成行。既不把积分近似当真实均值，也不把模型分位当真实条件分位。学习头只有开发假说，没有保证测试更好。

## 三个核心实验块

B1强基线闭合：固定任务、模型revision、点泛函、原点和输出H步身份。既有TimeXer等旧工件只有完全匹配才复用；TimesFM-3纳入新清单，Chronos-2原生输出与新头分别登记。

B2适配必要性：fold1/H3仅作实现smoke；路线门固定使用fold1的H3与H12两格训练/验证区比较原生中位数、稳健中点、只加全局训练均值残差的bias-only、共享affine输出校准（相同训练标签）、单纯形头。主方法需在H3/H12等权宏RMSE上比最强简单校准至少下降1%，MAE不劣化，且任一单格RMSE不得恶化超过1%；否则停止该头扩建，继续维护强基线。头为凸确定性优化，不通过重复种子制造独立样本；随机基线/MLP另用42/43/44。

B3固定benchmark：方法冻结后六折四视野，逐格、等权宏均、各种子和成本完整报告。已曝光历史区不能改称新盲测。SOTA需预先登记可复现最新强基线并完成协议桥接；内部门只决定是否推进，不定义全球SOTA。

## 可实施性与交接

NumPy单纯形头与数学测试已实现，Torch预测包已提供数据准备、train/validation、冻结checkpoint和test分离入口，TimeXer适配与合成训练已通。尚未完成TimesFM-3/Chronos-2当前revision的本地推理适配与实际训练期分位缓存，不应声称方法已在UrbanEV运行。已有显存约8GB；先profile单原点，失败则减少同原点计算批量或换CPU，不能静默拆分变量组改变方法。每个模型/头的新运行都有独立ID，原失败门不改判。

## 创新性与主要风险

分位数到均值、凸权重组合和偏差校准均有既有工作。此处只提出可否定的SOTA候选路线，全球新颖性和顶会贡献强度未建立。若增益只是bias/affine校准即可达到，就应报告这一结果而非包装新方法；若所有适配都不足以超过强端到端模型，下一步必须寻找新的输入信息或明确可重复的基础模型失败模式。

## Inference and Point-System Registry

每个基础模型code revision、checkpoint revision、fold、H分别保存缓存与头部，绝不跨fold或基础模型共享拟合权重。源码锁只说明已读版本，权重锁和运行环境尚待真实加载后记录，不把当前main分支名当固定权重。Chronos-2与TimesFM-3统一请求/读取0.1,...,0.9九分位；Chronos-2请求原生训练网格交集，任何不支持该网格的锁定模型必须作为新协议而非插值冒充原生输出。

- 缓存布局：[origin, H_step, zone, quantile]，区域顺序、原点索引及分位顺序各自哈希；原生点另存，不从排序后的q重新提取冒充原生值。
- 原生系统：官方native median，主表统一clip[0,1]后计算同一组RMSE/MAE；raw同时保留。
- 替代分位系统：clip再sort，只对bounded midpoint和simplex头使用；单独报告交叉/越界/排序导致中位改变比例，额外列postprocessed median控制。
- bias-only：用训练标签拟合y-native_median的全局均值残差，输出median+b。
- affine：用同一训练样本拟合y=a*median+b的最小二乘；另列midpoint affine控制，以排除中点自带偏差校准差异。所有控制都在最终输出clip，不按测试调整。
- simplex头：每个base-model@revision/fold/H一个共享11权重头；所有origin、step、zone展平成样本，lambda网格仅由验证clipped RMSE选择。训练区不使用验证或测试目标。
- 原点资格：训练第一个原点为小时索引168（历史0..167），最后原点满足s+H<=train_end；val原点从train_end起，所有H个target<val_end。可用此前train历史，但不能跨目标边界。
- 批量语义：一个独立origin的275变量为一个multivariate task；不同origin绝不组成变量组或cross-learning上下文。OOM先降低origin批量至1，若仍不行则记录不可行、尝试CPU并公开成本；不拆分275变量后继续声称同一方法。
- 主榜与适配公平性：native和adapted分别报告，任何训练头使用相同训练标签与validation选择；原生zero-shot免训练不等于额外受益。公开pretraining overlap unknown，不能承诺blind zero-shot。

## 实施门与资源记录

在完整benchmark之前必须逐项完成：基础模型权重/环境锁、真实单原点输出shape与native语义核验、275变量原点批量峰值显存、训练区缓存生成与哈希、头部收敛检查。当前这些基础模型门仍pending；现有NumPy核心与Torch TimeXer训练入口不被当作已完成基础模型实跑。公开清单将每个未完成项列出，不为达到评审分数虚构测量。

## 已完成的工程证据与未完成项

当前公共预测入口已通过全套46项本地测试；TimeXer和创新注意力合成训练通过。TimeXer在真实第一折275区域训练/验证前缀上完成1 epoch GPU链路profile，70个验证窗口，参数132675，进程内部训练/验证总计约6.23秒。该单轮结果不是收敛基线，不参与SOTA比较；没有执行测试段。基础模型本地推理、275区域全量缓存及学习头真实比较仍未执行。Q1–Q4及NumPy头独立证明/实现复核PASS；数学正确性不等于实际效果。
